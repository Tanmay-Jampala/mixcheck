////// The problem

AI coding tools are graded in English. Most Indian developers don't only speak English.

314.9M

bilingual Indians, Census 2011

0 / 23

Indian languages in HumanEval-XL's 23

When a developer types ek function likho instead of "write a function", does the assistant still write working code? MixCheck asks the same question 750 times and checks every answer against real tests.

////// How it works

From one prompt to two scores.

  1. 01

    Paired prompts

    25 coding tasks, each written 10 ways: plain English and its code-mixed versions.

  2. 02

    Three models

    Every prompt goes to Gemini, GPT-OSS 120B and GPT-OSS 20B.

  3. 03

    Find the function

    The grader pulls the function out of whatever the model replied with.

  4. 04

    Run the tests

    It runs against real test cases inside a 5-layer sandbox.

  5. 05

    Two scores

    Correct code: did the tests pass? Only code: did it reply with just the code we asked for?

////// Can it be fixed?

One line of English fixed it. Translating everything made it worse.

Worked

Add one English guard line

0% → 100%

"Reply with only one Python code block and nothing else." GPT-OSS 120B went from 0% to 100% "only code" and GPT-OSS 20B from 4%, with no loss in correct code.

////// Built for real conditions

Outages, slow networks, spoken prompts, and where the data comes from.

If a data centre goes down

Every AI request has a 30-second timeout and is retried up to 3 times with growing waits. Then it switches to a different company's data centre: Google and Groq back each other up.

A provider that just failed is skipped for a minute, so the next person doesn't wait too. A live test says when a backup answered; our recorded results never use one.

The 750 recorded results come from our own database, so they keep working even when every AI provider is down.

On a slow phone connection

On 2G, 3G or Data Saver, the site switches itself to a lite version: no 3D, no web fonts, no screenshots, and the dashboard loads only when you ask. You can switch any time from the top of the page.

Lite: about 60 KB for the whole page. The full version adds about 0.9 MB of 3D and screenshots, and the live dashboard is about 11 MB, so lite loads it only when asked.

Ask out loud

Speak a coding request in Hinglish, Benglish, Kanglish, Tanglish or Odia-English. Gemini writes down exactly what you said, in the letters people type in chats; Whisper on Groq is the backup.

MixCheck warns when the word for "only" gets lost on the way to text: the same failure we found with translate-first.

Where the data comes from

We don't train any model. MixCheck tests existing ones: Gemini Flash-Lite from Google, and GPT-OSS 120B and 20B run by Groq.

25 tasks, each asked 10 ways. Prompts were drafted with AI help and checked by native speakers (Kanglish by Takshak P; Tanglish and Odia checks are in progress). Every test file is checked against a reference solution.

One SQLite database holds the 25 tasks, 250 prompts, 750 answers and grades, the fix experiment, and a log of every live test. Download it from the dashboard.
